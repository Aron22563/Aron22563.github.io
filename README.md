# My Personal Website & Blog

This is my personal website where I showcase projects, blog posts, and some of my experiments with tech.  
Built with [Jekyll](https://jekyllrb.com/) and deployed with GitHub Pages. The site is based on the [Jekyll Chirpy Theme](https://github.com/cotes2020/jekyll-theme-chirpy).

## Features

- Blog for documenting experiments and small projects.
- Portfolio section highlighting personal projects.

There is not much more to see here as no documentation is necessary. :)
