**Dotcop** is a configuration synchronization tool for individuals. I developed this as i felt the need to have deployable configuration that wasnt met by any other existing software. What this software is trying to propose is to treat individual program configuration as packages managed by dotcop. This simplifies the user experience of customizing different parts of their software.

<br>
The management happens through a combination of symlinking package configuration files from a centralized point whilst allowing advanced package management features and package metadata storing.
<br>
<br> 
## Similar programs
### Ansible 
_Ansible_ provides similar functionality and integrates well with broader configurations through system wide package managers. Dotcop aims for program specific configurations which can be tedious to set up through Ansible.<br>
Check out this: [Ansible vs. Dotcop](/placeholder)

### GNU Stow 
_GNU Stow_ is a basis for the current implementation of dotcop and helps in managing symlinks to the correct places. This usage might get built directly into the project later on.
